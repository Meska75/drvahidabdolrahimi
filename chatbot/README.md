# چت‌بات دستیار دکتر عبدالرحیمی

این پوشه **تمام** کد هوش مصنوعی را نگه می‌دارد تا دنبال کردن آن ساده باشد.
سایت Django فقط ویجت را نشان می‌دهد و درخواست را به اینجا می‌فرستد.

## راه‌اندازی سریع

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

سپس در پنل ادمین: **چت‌بات هوش مصنوعی → ۱. پروفایل‌ها**.
پروفایل «مطب دکتر عبدالرحیمی» از قبل ساخته شده (آیکون پیش‌فرض خاموش است).

1. اتصال مدل چت بسازید (Base URL و کلید درگاه + نام مدل) و تست کنید.
2. همان اتصال را در پروفایل به‌عنوان «اتصال فعال» انتخاب کنید.
3. تیک «نمایش آیکون روی سایت» را بزنید.
4. برای RAG: اتصال embedding + آپلود فایل + اکشن «افزودن به RAG».

## نسخه لینک (سایت دیگر)

```
python manage.py run_chatbot_link --host 0.0.0.0 --port 8100
```

سایت دیگر باید `session_id` را در localStorage همان مرورگر نگه دارد (مثل کوکی ۷روزهٔ ویجت).
اگر نفرستد، سرور یکی می‌سازد و در پاسخ برمی‌گرداند — همهٔ کاربران را روی `anonymous` جمع نمی‌کند.

```
POST /v1/greeting   { language, session_id }
POST /v1/chat       { language, session_id, message }
POST /v1/history    { language, session_id }
POST /v1/clear      { language, session_id }
```

همه با هدر `X-Chatbot-Key`. پاسخ همیشه `session_id` و `memory_days` دارد.

## حافظه گفتگو (بدون اکانت)

شناسه روی کوکی `dr_chat_id` به مدت ۷ روز از **آخرین پیام** می‌ماند.
پاپ‌آپ همان تاریخچه را از سرور می‌آورد. سطل‌زباله داخل هدر گفتگو را پاک می‌کند.
مدل با `DjangoConversationHistory` + `trim_messages` مسیر چت را می‌بیند.

## محتوای سایت داخل RAG

در پروفایل، بخش‌های سوالات، خدمات، پزشک، مطب، تیم و مقالات منتشرشده را جدا تیک بزنید و «ایندکس محتوای فعلی سایت» را بزنید.
تیک «به‌روزرسانی خودکار» ذخیره و حذف بعدی همان بخش‌ها را به RAG همان پروفایل می‌فرستد.
ویجت و `POST /v1/chat` هر دو همان کالکشن را جستجو می‌کنند؛ پروفایل لینک اگر این تیک‌ها را نداشته باشد، محتوای این سایت را نمی‌بیند.
فایل‌های آپلودی کنار این محتوا می‌مانند.

ویجت و `POST /v1/chat` هر دو همان قطعه‌ها را جستجو می‌کنند. بردارها در دیتابیس خود سایت ذخیره می‌شوند.
